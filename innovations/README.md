# RTSA 实时频谱分析仪核心技术创新点全景

本项目针对 **Xilinx Zynq UltraScale+ RFSoC (XCZU47DR)** 平台，在上位机软件架构、嵌入式 Linux 显示渲染、AXI DMA 驱动与高速数据交换、实时频域信号处理等方面进行了深入的工程创新与性能攻关。

针对嵌入式平台**“无硬件 GPU 加速、Cortex-A53 弱算力、PL 端超高吞吐（数万至数十万 FPS）”**的严苛工况，本项目提炼出以下核心技术创新点：

## 创新价值总结

1. **极致轻量化**：在完全不依赖 Mali GPU 硬件驱动的前提下，充分压榨 4 核 ARM 架构，达成桌面级专业仪表的刷新流畅度；
2. **高容错与高鲁棒性**：面对 PL 端高达数十万 FPS 的数据冲击，系统具备全链路流量削峰与自愈能力，杜绝内存泄漏与 DMA 引擎挂死；
3. **软硬件全栈闭环**：从 Linux 内核字符设备驱动、mmap 共享内存，到 Qt 上位机无锁环形管道，形成高度优化的软硬件协同范例。
