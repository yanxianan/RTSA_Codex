## 3. 关键实现证据

### 3.1 数据源和帧管线

- `ISpectrumSource` 定义统一生命周期、状态通知和帧回调；
- `SpectrumSourceFactory` 可选择 `simulated` 或 `dma`；
- `SpectrumPipeline` 负责校验、轨迹处理、发布和统计；
- `LatestFrameStore` 只保留最新完整帧，避免 GUI 排队绘制过期数据；
- Marker、Peak Search、区间测量核心和 CSV 使用完整频点，不使用绘制包络。

### 3.2 CPU Raster 与异步离屏渲染

- 频谱控件继承自 `QWidget`，最终绘制使用 Qt Raster `QPainter`；
- 静态层和离屏目标图使用 `QImage::Format_RGB16`；
- 单个 `std::thread` 离屏 worker 负责几何和曲线栅格化，不是线程池，也没有按四个 CPU 核做负载均衡；
- 新渲染请求会覆盖尚未开始处理的旧上下文，保证显示最新状态；
- 主线程 `paintEvent()` 仅绘制脏区；离屏结果不可用时允许同步 Raster 回退；
- 绘制降采样按屏幕列计算最小值/最大值，但当前轨迹实际连接各列最大值绘制折线。

### 3.3 瀑布图

- 历史图像使用 `QImage::Format_Indexed8`；
- 历史深度范围 64～2,048 行，默认 512 行；
- 提供 Classic Rainbow、Rohde & Schwarz、Ironbow、Deep Ocean、Grayscale 五种色表；
- 新帧写入环形缓冲的一行；
- 缓冲填满后通过两个物理切片绘制连续历史；
- `rtsa_waterfall_tests` 已加入当前测试集，并在 2026-11-04 的 20/20 运行中通过。

### 3.4 Marker 与测量

- M1～M4、Delta Marker、Peak Search、Next/Previous Peak 和峰值门限位于当前界面；
- `SpectrumMeasurements` 提供区间峰值和线性功率域信道功率计算；
- 当前四个标签页没有区间峰值或信道功率控件；
- 因此只能表述为“核心实现和单元测试存在，GUI 入口未提供”，不能写成“GUI 已验证”。

### 3.5 DMA 应用与驱动

当前 DMA 路径已经越过“仅预留接口”阶段：

- 用户态源封装设备打开、映射、启动、`poll` 等待、批量出队和槽位归还；
- 驱动使用 `dma_alloc_coherent` 分配 128 个 132 KiB 缓冲，共约 16.5 MiB；
- 设备树 compatible 为 `rtsa,spectrum-dma`，DMA 名称 `rx_chan`；
- 完成队列满时，驱动会将对应槽位重新提交，避免槽位永久脱离接收环；
- 当前载荷是 64 B 小端帧头 + `int16` 对数幅度（0.01 dB/LSB，dBFS）；绝对 dBm 仍由 `calibration_offset_db` 和外部校准表决定；
- 当前载荷带 64 B 版本化帧头，Center、Span、频点数、Trace 模式、窗函数和校准偏移由帧头携带；`DmaSourceConfig` 只保留设备路径、刷新率和兜底配置；
- PS 通过 `/dev/uioX` 的 `rtsa_regs` 写入 staging 配置并 commit；PL 在 `0x120` 原子快照，`pl_config_latch` 在当前频谱帧完整输出后锁存 active 配置；
- 运行中修改 Center/Span/Max Hold 只换下一帧帧头；DDS 频率额外 resync；DMA 模式、CIC、HB 只复位 PL 数据通路并重配 CIC；AXI DMA 描述符环全程不停；
- `tb_reg_config`、`tb_config_latch`、`tb_config_pipeline` 已验证 staging、commit 快照、帧边界锁存、软/DDS/硬参数分类和状态回读；当前 Trace 模式与窗函数仍是 PL 固定默认值；
- 新增 `CIC=1` 宽带旁路：HB 仍可抽取，`CIC=1/HB=0` 时 FFT 输入 312.5 MSPS、span 312.5 MHz；`tb_dec_bypass` 与 `tb_wideband_fft_smoke` 已通过；
- `tb_logic_top_modified` 的 221.78 µs PASS 对应 P1 数据路径；P2 解耦控制链由 `tb_config_pipeline` 覆盖，完整 `logic_top` 数据通路待板端复验；
- 当前 PL 默认帧的 `calibrated` 仍为 false，绝对 dBm 需要后续校准。
- 2026-11-05 完成 `tb_logic_top_modified` 完整行为仿真，221.78 µs PASS，覆盖抽取、75% 重叠帧、Max Hold、频率触发、时域捕获和格式化频谱 DMA 输出。

板端吞吐、缓存一致性、断流恢复、帧边界和 PL 真实输出仍需实测。

### 3.6 文件、配置与日志

- PNG 仅截取 Raster 频谱控件，不包含瀑布图和右侧参数面板；
- CSV 在导出开始时固定完整帧快照，并使用 `QSaveFile` 原子提交；
- JSON 模拟场景格式为 v2、兼容 v1，文件上限 1 MiB；
- `QSettings` 配置格式为 v4，支持旧版本迁移和损坏回退；
- 日志使用 UTC 时间、级别、模块、事件和原因字段，单文件大小及保留数量有界。

## 5. 历史验证结果

以下记录来自仓库原有报告，执行日期为 2026-07-26，环境为 Windows、Qt 6、MinGW 13.1、CMake/Ninja。当时测试集只有 14 项；当前测试集已扩展为 20 项，并在 2026-11-04 通过。

### 5.1 Windows Qt 6 Debug

- 构建通过；
- 历史 CTest 结果：14/14 通过；
- 完整应用离屏冒烟通过；
- 16,384 点、请求 1,000 FPS 时记录约 999.95 FPS；
- 对应内部 float32 数据率约 65.53 MB/s；
- 历史 1920×1080 主窗口显示采样约 32.62 FPS。

### 5.2 Windows Qt 6 Release

- 构建通过，启用 warnings-as-errors；
- 历史 CTest 结果：14/14 通过；
- 16,384 点、请求 1,000 FPS 时记录约 1,000.01 FPS；
- 对应内部 float32 数据率约 65.54 MB/s；
- 历史 1920×1080 主窗口显示采样约 33.70 FPS；
- 历史显示延迟 P95 记录约 16.5 ms。

这些数值只用于说明当时 PC 测试条件，不能外推为 ZU47DR 板端性能。当前 20 项测试已在 2026-11-04 复测通过。
