# 专题 04：Indexed8 瀑布图环形缓冲与双切片绘制

## 1. 文档范围

本文说明 `WaterfallPlotWidget` 当前如何保存历史频谱、滚屏、换色和重绘。

| 项目 | 状态 |
|---|---|
| `Format_Indexed8` 历史图、环形头指针、新帧单行写入、双切片绘制 | 已实现 |
| 64 至 2048 行历史深度和五种色表 | 已实现 |
| `rtsa_waterfall_tests` | 已注册 |
| 当前 15 项测试复测 | 本次未执行 |
| 目标板单帧耗时和长期稳定性 | 板端待验 |

“双切片”描述的是同一张环形图在逻辑顶部和底部如何拆成两个源矩形，不是两张独立历史图，也不是不需要任何 `drawImage()` 成本的零拷贝显示。

## 2. 缓冲结构

历史图由以下状态组成：

```text
bufferImage_      Format_Indexed8 环形图
bufferWidth_      当前绘图区目标列数
historyDepth_     64 至 2048 行，默认 512
headRow_          最新一行在物理图中的索引
rowCount_         已写入行数，最大等于 historyDepth_
colorTable_       256 项调色板
```

一张宽度为 `W`、深度为 `D` 的 Indexed8 图约占 `W * D` 字节。以 1,920 列为例：

| 深度 | Indexed8 内存 | 同尺寸 ARGB32 内存 |
|---:|---:|---:|
| 512 | 约 0.94 MiB | 约 3.75 MiB |
| 2,048 | 约 3.75 MiB | 约 15 MiB |

实际宽度取决于窗口和边距，不能固定写成 1920。

## 3. 单帧写入

`addFrame()` 的处理顺序：

1. 在每个屏幕列的对应 bin 范围内取最大值，保留窄带峰；
2. 将最新行索引向前移动一格；
3. 直接将 256 档颜色索引写入 `bufferImage_` 的新扫描线；
4. 将 `rowCount_` 增长到历史深度上限；
5. 只标记瀑布绘图区更新。

稳态运行时，不执行整张历史图的 `memmove`。每帧主要写入一行颜色索引，因此历史深度增加时，单帧写入量基本不随深度增长。

## 4. 环形布局与双切片

`headRow_` 指向最新行。逻辑上的时间顺序是：

```text
screen top    -> [headRow_ ... historyDepth_ - 1]
screen bottom -> [0 ... headRow_ - 1]
```

缓冲区未填满时，只绘制从 `headRow_` 开始的 `rowCount_` 行。填满后，绘制拆成两个连续源矩形：

- 切片 1：`[headRow_, historyDepth_)`，其中包含较新的数据；
- 切片 2：`[0, headRow_)`，其中包含更早的数据。

这种布局避免了滚屏时的历史数据搬移，但每帧仍要执行图像缩放和绘制。实际绘制成本受绘图区高度、目标 QPA、缩放路径和窗口系统影响，不能只由算法结构推导出固定毫秒数。

## 5. 调色板切换

图像像素保存的是 0 至 255 的幅度索引。切换色表时调用 `QImage::setColorTable()`，不需要改写历史像素。当前界面包含：

- Classic Rainbow；
- Rohde & Schwarz；
- Ironbow；
- Deep Ocean；
- Grayscale。

颜色索引的量化结果会受参考电平、底电平和当前色表影响；换色只改变显示，不改变历史频谱数据。

## 6. 尺寸变化

窗口尺寸改变时，历史图需要重建：

- 宽度不变时按行复制现有历史；
- 宽度增大时使用双线性插值；
- 宽度减小时使用峰值保持，尽量避免窄信号在缩小后消失。

因此，“环形缓冲永不搬移”只适用于固定几何下的稳态滚屏。调整窗口、切换全屏或改变历史深度都会触发一次历史重建。

## 7. 证据与验证

`tests/tst_Waterfall.cpp` 覆盖了滚屏方向、新旧信号保留、色表和尺寸变化等行为。当前文档不再保留 `0.15 ms`、`1 微秒`、`56 倍` 等旧数字，因为这些结果没有与当前源码、测试环境和原始计时日志建立可追溯关系。

板端验证至少记录：

| 场景 | 指标 |
|---|---|
| 512、1,024、2,048 行 | 每帧写入和 `paintEvent()` 耗时 |
| 频谱/瀑布/双视图 | CPU、内存带宽和显示帧率 |
| 色表切换 | 是否出现卡顿或历史内容变化 |
| 全屏切换 | 重建耗时、窄峰是否保留 |
| 长时间运行 | 内存趋势、行计数和环形边界 |
