# 专题 03：3 dB excursion 与 NMS 的峰值搜索

## 1. 文档范围

本文描述 `SpectrumPlotWidget::findPeaks()`、峰值门限和 M1 至 M4 相邻峰值导航的当前实现。

| 项目 | 状态 |
|---|---|
| 峰值门限、局部极大值、左右 excursion、NMS、循环导航 | 已实现 |
| 宽高斯峰、带噪裙边、门限拒绝等测试代码 | 已实现并注册 |
| 当前 15 项测试复测 | 本次未执行 |
| 真实 PL 频谱下的峰值准确率和耗时 | 板端/协议待验 |

## 2. 输入与输出

峰值搜索直接读取当前完整频谱帧的 `bins`，不是读取已经压缩到屏幕列后的折线，也不是只对 Marker 附近做局部最大值。

- 输入点数：`frame_->bins.size()`
- 门限：`peakThreshold_`，默认由界面设置为 `-100 dBFS`
- 核心参数：`kExcursion = 3.0F`
- 输出：按 bin 从小到大排列的候选峰索引

运行前会排除非有限值。门限判断使用 `val < peakThreshold_`，等于门限的点仍可参与搜索。

## 3. 已实现算法

### 3.1 局部极大值

对每个 bin 检查：

```text
当前值 >= 左侧有效值
当前值 >= 右侧有效值
```

边界点只检查存在的一侧。相邻值不是有限数时，该方向不阻止当前点成为候选。

平顶峰只保留首个点：如果左侧点与当前值完全相等，当前点跳过。这避免了整段平顶重复生成峰值。

### 3.2 左右 excursion 检测

向左和向右分别记录扫描过程中出现过的最低值，并在遇到更高点时停止。正常判据是：

```text
peak_value - range_minimum >= 3.0 dB
```

这样可以把“更高主峰侧翼上的小起伏”排除。源码还包含边界回退条件：

- 左侧满足 `i <= 3` 或当前落差至少 1 dB；
- 右侧满足 `i + 4 >= n` 或当前落差至少 1 dB。

因此，实际代码不是严格的“两侧必须都达到 3 dB 才通过”。靠近边界或仅达到 1 dB 落差时也可能被接受。文档、测试和界面说明不应把这一实现描述成无条件的工业标准 3 dB 判据。

### 3.3 非极大值抑制

候选峰生成后，相邻候选之间计算中间谷底：

```text
valley = min(left_peak, right_peak, bins between both peaks)
```

如果左右候选相对同一谷底的落差都小于 3 dB，则只保留更高者；否则两个候选都保留。该步骤用于合并同一主瓣内部未充分分离的起伏。

### 3.4 峰值导航

- `peakSearch()` 优先从 `findPeaks()` 结果中选取最高候选；
- 没有合格候选时，退回完整频点中的全局最大值；
- `nextPeak()` 向右查找第一个更高频峰值，到达末尾后循环到最左峰；
- `previousPeak()` 向左查找，到达开头后循环到最右峰；
- 导航结果写入当前活动 Marker，并触发 Marker 与离屏图更新。

## 4. 与 dBFS 转换的关系

DMA 输入到 dBFS 的核心转换位于 `DmaSpectrumSource`：

```text
dBFS = 20 * log10(abs(raw) / fullScale)
```

这不是峰值搜索算法本身。当前 `calibrated` 为 `false`，因此峰值搜索结果适合作为相对显示和交互值，不能在没有协议与标定证据时写成绝对输入功率测量。

## 5. 证据与限制

已有测试覆盖：

- 使用完整分辨率帧而不是显示抽点；
- 四 Marker、Delta 与相邻峰值导航；
- 宽高斯峰和带噪裙边时定位峰顶；
- 门限拒绝低信号。

当前文档不保留“100% 锁定真实峰”“1024 点平均 15 微秒”等旧结论，因为这些结果没有附带当前源码、输入数据、重复次数和板端环境。

已知限制：

- excursion 扫描可能跨越较多 bin，不能仅凭循环结构断言固定微秒级复杂度；
- 频点和噪声底受 PL 窗函数、FFT 缩放、RBW 和短包边界影响；
- 边界回退可能接受较弱的边缘峰；
- 真实多音、邻道、杂散和噪声底场景需要板端数据验收；
- 当前测试集没有在本次文档整理中重新执行。

## 6. 验证建议

| 场景 | 检查点 |
|---|---|
| 单音 | 峰位置、Marker 频率和幅度连续性 |
| 双音 | 相邻峰是否分开，NMS 是否错误合并 |
| 宽高斯峰 | 是否定位峰顶而不是近峰裙边 |
| 低 SNR | 门限变化是否稳定，是否出现 Marker 跳动 |
| 平顶峰 | 是否只产生一个代表峰 |
| 边缘信号 | 边界回退是否产生可解释结果 |
| 大规模频谱 | 65,536 点下的调用耗时和最坏扫描路径 |
