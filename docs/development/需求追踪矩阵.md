## 1. 状态定义

| 状态 | 含义 |
|---|---|
| PC/离屏已验证 | 仓库历史记录显示在 Windows Qt 6 环境通过实现和自动测试；不等同于本次复测 |
| 已实现 | 当前源码存在对应实现，但本次未执行验证 |
| 已实现，板端待验 | 软件路径存在，仍需目标板、真实 PL 数据或目标 QPA 确认 |
| 核心已实现，GUI 未提供 | 核心类和测试存在，但当前界面没有可操作入口 |
| 协议/标定待确认 | 需要外部输入冻结语义后才能完成验收 |
| 未实现 | 当前需求仍属于扩展范围 |
| 未验证 | 没有足够证据，不能以短时测试或 PC 结果替代 |

当前测试集共 20 项。仓库历史报告中的 14/14 属于 2026-07-26 的旧测试集；2026-11-04 已在 Windows Qt 6.10.2 Debug 构建中完成 20/20 通过。

### 2.5 DMA 软件链路

该部分对应需求文档第 9 节，不新增需求编号。

| 项目 | 状态 | 当前证据与边界 |
|---|---|---|
| DMA 用户态源 | 已实现，板端待验 | `/dev/rtsa_dma`、mmap、poll、ioctl、132 KiB 槽、V1 帧解析和停流唤醒 |
| DMA 内核驱动 | 已实现，板端待验 | dmaengine、coherent 缓冲、128 × 132 KiB、`frame_size`、溢出重提交和设备树示例 |
| 载荷解析 | 已实现，板端待验 | 64 B V1 帧头 + 1024 × int16；Center/Span/epoch 随帧返回 |
| 幅度语义 | 协议/标定待确认 | `int16` 对数 dBFS（0.01 dB/LSB），帧头带 calibration offset；RBW/PSD/绝对 dBm 仍需标定 |
| 312.5 MHz 宽带 | 已实现，板端待验 | `CIC=1/HB=0` 旁路，0% 重叠，1024 点 FFT |
| 真实吞吐和恢复 | 板端待验 | 需要 PL 连续流、固定图样、断流/复位和目标板 CPU/DDR 实测 |

## 4. 验收拆分

### 4.1 原始一期目标

原始一期目标包括 Windows 模拟版、Qt 6/Qt 5.15 兼容、无 GPU 显示、基本仪器功能、配置/导出、24 小时长稳和 ARM64 板端模拟运行。该清单保留作为原始基线。

### 4.2 当前仓库可确认范围

| 条款 | 状态 | 说明 |
|---|---|---|
| Windows Qt 6 模拟版 | PC/离屏已验证 | 基于 2026-07-26 历史记录 |
| Qt 5.15.x 实际构建 | 未验证 | 缺少 Qt 5.15 工具链证据 |
| 模拟噪声/信号/扫频/瞬态 | PC/离屏已验证 | 行为、场景和 smoke 有历史记录 |
| 1,024～65,536 点 | PC/离屏已验证 | 数据和绘图测试 |
| 无 GPU Raster 路径 | PC/离屏已验证 | PC 上无 OpenGL/Qt Quick/Vulkan 链接依赖 |
| 频谱/瀑布/Marker/轨迹 | 已实现 | 瀑布测试已通过；当前 20 项 CTest 全通过 |
| PNG/CSV/配置/日志 | PC/离屏已验证 | 基于历史测试 |
| 区间峰值/信道功率 GUI | 未实现 | 只有核心计算和测试 |

## 5. 后续关闭路径

1. 提供 PetaLinux 2023.2 extensible SDK/sysroot，完成 Qt 5.15 AArch64 构建；
2. 在 ZU47DR 上确认 QPA、屏幕、字体和输入设备；
3. 用固定图样验证驱动、UAPI、帧边界、缓存和断流恢复；
4. 板端确认 V1 帧头、`frame_size` 和 312.5 MHz 旁路；
5. 完成 RBW/ENBW、每 bin 功率/PSD 和绝对标定；
6. 补齐真实 DMA 自动重试与错误分类；
7. 单独完成区间测量 GUI 后再更新 `FR-MEAS-001/002/005`；
8. 重复执行当前 20 项测试，并在板端环境补充验证。
