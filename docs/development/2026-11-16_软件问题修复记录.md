# 2026-11-16 软件问题修复记录

本轮修复不依赖开发板，修改完成后已完成 Windows Qt/MinGW 构建和 CTest。

## 修复内容

### 1. DMA 驱动完成状态

`driver/DMA/rtsa_dma_driver.c`

- 删除完成回调中覆盖 `slot->info.status` 的 `status = 0`。
- 现在 short-frame（bit1）和 DMA error（bit2）会真正传到用户态。
- `RTSA_IOC_DEQUEUE` 的 `copy_to_user` 失败时，将槽位重新提交给 DMA，避免槽位永久丢失。

### 2. UAPI 版本校验

`driver/DMA/rtsa_dma_uapi.h`、`driver/DMA/rtsa_dma_driver.c`、`src/sources/DmaSpectrumSource.cpp`

- 新增 `RTSA_IOC_GET_VERSION`，UAPI 版本提升到 3。
- 应用打开 `/dev/rtsa_dma` 后先校验 `RTSA_UAPI_VERSION`；驱动与应用版本不一致时直接报错，不再继续 mmap/启动。

### 3. DMA 应用层健壮性

`src/sources/DmaSpectrumSource.cpp`

- `info.status != 0` 的帧不再复制/发布到 UI，只计入丢帧。
- `RTSA_IOC_SET_FRAME_SIZE` 失败时直接清理并退出，不再用驱动默认 131136 字节帧长继续启动。
- `poll()` 检查 `POLLERR/POLLHUP/POLLNVAL`，设备异常时退出采集线程。
- 配置 commit 后使用 `waitForActiveEpoch()` 等待 PL 真正切换；200 ms 未生效会明确告警。

### 4. UIO/寄存器映射

`src/core/PlRegisterMap.*`

- 新增 `waitForActiveEpoch()`。
- 新增 `normalizeCicRate()`：`0/1` 归一到 1，`2/3` 归一到 4，其余限制在 `4..8192`。
- UIO 映射大小改为读取 `/sys/class/uio/*/maps/map0/size`，不再无条件按 8 KiB 映射。

### 5. UI 与硬件语义一致

`src/ui/MainWindow.*`

- DMA 模式下 Span 锁定为硬件 FFT span，禁用 Span、起始/终止频率和快捷频宽按钮；不再出现 UI 200 MHz、实际 9.765625 MHz 的不一致。
- DMA 模式下禁用 Trace 模式和平均次数控件，因为它们对 `logBins` 帧不会生效。
- CIC 输入 2/3 时自动纠正为 4，并同步更新硬件 span。
- DMA 模式禁止通过缩放手势/框选修改 Span。
