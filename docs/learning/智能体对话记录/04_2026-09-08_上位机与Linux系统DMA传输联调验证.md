### 🤖 智能体回复

### 直接结论

1. **需要驱动，但不需要从头手写内核驱动！**
   - Xilinx Linux 内核自带成熟的 AXI DMA 驱动（`drivers/dma/xilinx/xilinx_dma.c`，基于内核 DMAEngine 框架）。
   - **痛点**：内核原生的 DMAEngine **不会向用户空间暴露 `/dev/xxx` 设备节点**。
   - **最优解**：直接使用 Xilinx 官方标准的 **`dma-proxy`** 内核模块（几百行代码，PetaLinux 官方配方即可加入）。它作为内核 DMAEngine 到用户态的跳板，利用 `dma_alloc_coherent` 分配连续环形缓冲，暴露 `/dev/dma_proxy_rx` 字符设备，上层应用直接 `mmap` + `ioctl/poll` 即可实现高吞吐零拷贝。
   - **备选方案**：若完全不想碰内核模块，可用内核自带的 `uio_pdev_genirq`（映射 AXI DMA 寄存器及中断）+ 开源的 `udmabuf`（分配物理连续内存）。但该方案要在用户态维护 Scatter-Gather 描述符，健壮性不如 `dma-proxy`。

### DMA 打通与分步验证全流程

必须采用**分层解耦**的方式逐步打通，严禁一开始就让 Qt 上位机直接联调真实射频 FFT。

---

#### 第 1 步：PL 端独立闭环（测试图样 + 严查 TLAST）

在接真实的 ADC/DDC/FFT 之前，PL 侧先换成一个**测试图样生成器（Test Pattern Generator）**：
1. **产生确定性数据**：
   - 帧头固定填 64 字节（Magic `0x52545341`，帧号递增，点数如 16384）。
   - 载荷填递增计数器 `Ramp`（0, 1, 2, 3...）或固定频率单频点峰值。
2. **抓 ILA 严查 AXI4-Stream 信号**（这是 90% 联调卡死的原因）：
   - **`TLAST`**：必须且只能在**单帧的最后一个 AXI Beat**拉高 1 个时钟周期。若漏发 TLAST，S2MM 通道会挂起一直等待；若提前发，会导致短帧中断报错。
   - **`TKEEP`**：必须全 1，保证总线宽度全对齐。
   - **限速机制**：PL 端必须加入输出限速计数器（如固定 50 FPS 或 200 FPS），切忌全速把未加限速的 FFT 结果（几十万 FPS）无脑冲向 PS DDR，否则会瞬间打满总线并发生 FIFO 溢出。

#### 第 3 步：纯 C 独立命令行验证工具（不上 Qt，先测吞吐与数据完整性）

编写一个独立的验证小工具 `dma_verify.c`，在板端 Linux 终端直接运行，排查硬件与驱动问题：

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <fcntl.h>
#include <sys/mman.h>
#include <sys/ioctl.h>
#include <unistd.h>
#include <poll.h>

#define BUFFER_SIZE (256 * 1024)   // 256KB 足够容纳 65536 点 + 帧头
#define DMA_MAGIC   0x52545341     // "RTSA"

// dma-proxy 标准交互结构
struct dma_proxy_channel_interface {
    unsigned int buffer_length;
    enum { PROXY_NO_ERROR = 0, PROXY_TIMEOUT, PROXY_ERROR } status;
};

#define START_XFER _IOW('a', 'a', int32_t *)
#define FINISH_XFER _IOW('a', 'b', int32_t *)

int main() {
    int fd = open("/dev/dma_proxy_rx", O_RDWR);
    if (fd < 0) {
        perror("Failed to open /dev/dma_proxy_rx");
        return -1;
    }

    // 映射内核预分配的 DMA Coherent Buffer
    uint8_t *buf = (uint8_t *)mmap(NULL, BUFFER_SIZE, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if (buf == MAP_FAILED) {
        perror("mmap failed");
        close(fd);
        return -1;
    }

    printf("Starting DMA RX verification loop...\n");

    for (int frame = 0; frame < 100; frame++) {
        // 1. 发起传输请求
        ioctl(fd, START_XFER, NULL);

        // 2. 等待传输完成中断 (阻塞 poll)
        struct pollfd pfd = { .fd = fd, .events = POLLIN };
        int ret = poll(&pfd, 1, 1000); // 1秒超时
        if (ret <= 0) {
            printf("[Frame %d] DMA Transfer Timeout!\n", frame);
            break;
        }

        // 3. 结束传输，驱动处理缓存一致性
        ioctl(fd, FINISH_XFER, NULL);

        // 4. 校验帧头与内容 (假设前 4 字节为 Magic，后续为 Ramp 递增 int32)
        uint32_t magic = *(uint32_t *)(buf);
        if (magic != DMA_MAGIC) {
            printf("[Frame %d] Magic Mismatch! Got: 0x%08X, Expected: 0x%08X\n", frame, magic, DMA_MAGIC);
            continue;
        }

        // 校验 Ramp 递增有效性
        int32_t *payload = (int32_t *)(buf + 64);
        int error_count = 0;
        for (int i = 0; i < 1024; i++) {
            if (payload[i] != i) {
                error_count++;
                if (error_count <= 3) {
                    printf("  Mismatch at bin %d: got %d, expected %d\n", i, payload[i], i);
                }
            }
        }

        if (error_count == 0) {
            printf("[Frame %d] Passed! (Verified 1024 ramp points)\n", frame);
        } else {
            printf("[Frame %d] FAILED! Total bin mismatches: %d\n", frame, error_count);
        }
    }

    munmap(buf, BUFFER_SIZE);
    close(fd);
    return 0;
}
```

**验收标准**：
- 连续读取 10,000 帧无超时、无 Magic 错位。
- 若帧数据发生错位（例如本属于下一帧的头跑到了中间），说明 PL 的 `TLAST` 长度与 DMA 设置的传输长度不一致，或者 PL 发生数据下溢/溢出导致漏 beat。

#### 第 4 步：对接上位机架构（`DmaSpectrumSource` 实现）

在确认独立命令行测试通过后，即可在上位机工程中实现 `IDmaDevice` 与 `DmaSpectrumSource`，并接入既有的 `SpectrumPipeline`。

关键架构与防坑法则：

```text
/dev/dma_proxy_rx 
   └─> IDmaDevice (LinuxDmaDevice: mmap, ioctl, poll)
          └─> DmaSpectrumSource (采集工作线程)
                 ├─> SpectrumFrameParser (校验 Magic、Version、BinCount、Epoch)
                 ├─> RawSpectrumConverter (NEON / 定点转 float32 dBFS)
                 ├─> 拷贝入 FramePool 预分配帧
                 ├─> 立即归还 DMA Buffer (严禁 GUI 线程霸占 DMA 环形缓冲)
                 └─> 提交给 SpectrumPipeline -> LatestFrameStore -> Qt 界面
```

##### 必须执行的 3 个设计原则：
1. **DMA Buffer 即取即还**：
   - 驱动通常维护一个 16~32 槽位的环形缓冲区。
   - Worker 线程在 `poll` 唤醒后，完成数据解析或拷贝至 `FramePool` 后，**必须立刻释放/归还 DMA 缓冲区**。
   - 绝对不要把 DMA 缓冲区指针直接塞进 Qt 信号槽传给 GUI。如果 GUI 渲染掉帧卡顿 20ms，就会把所有 DMA Ring Buffer 占满，导致 PL 端 AXI-Stream 反压，PL FIFO 溢出崩溃。
2. **Cache 一致性同步**：
   - ZU47DR 的 PS 是 4 核 Cortex-A53。若 DMA 挂载在非一致性接口（如 HP 端口而不是 HPC 端口走 CCI 缓存一致性），驱动在将数据交给用户态读之前，**必须执行 `dma_sync_single_for_cpu` 做 D-Cache Invalidate**，否则 PS CPU 读到的是 CPU 缓存里的陈旧数据。
3. **参数下发与数据帧 Epoch 闭环**：
   - 当用户在 Qt 界面修改 Center Frequency 或 Span 时，PS 通过 AXI-Lite 寄存器下发配置。
   - PL 必须在帧边界生效新参数，并将生效的版本号（`configurationEpoch`）打在下一帧的 64 字节帧头里。
   - 上位机 `SpectrumFrameParser` 识别到新 Epoch 才刷新坐标轴，杜绝“新坐标套用旧数据”导致的频谱频率显示跳变。

### 🤖 智能体回复

自研高性能 AXI DMA 驱动，**绝不要从零用 `ioremap` 去硬写寄存器和解析 SG（Scatter-Gather）描述符链表**（这是吃力不讨好的反模式，极易引发死锁和硬件总线挂死）。

工业界标准范式是：**基于 Linux 内核的 `DMAEngine` 框架开发一个字符设备驱动（Character Device）**。
- **底层**：复用内核自带的 `xilinx_dma.c` 接管硬件寄存器与中断；
- **你的驱动**：负责**管理环形缓冲区（Ring Buffer）**、**提交 DMAEngine 描述符**、**实现中断回调**，并向用户态暴露 `mmap`（零拷贝）+ `poll`（事件等待）+ `ioctl`（出队/入队控制）标准接口。

### 2. 用户态与驱动交互头文件 (`rtsa_dma_uapi.h`)

定义 ioctl 控制协议与环形缓冲区结构：

```c
#ifndef _RTSA_DMA_UAPI_H_
#define _RTSA_DMA_UAPI_H_

#include <linux/types.h>
#include <linux/ioctl.h>

#define RTSA_RING_BUFFER_COUNT  16          // 环形缓冲数量
#define RTSA_BUFFER_SIZE        (256 * 1024) // 每块 256 KB，足以容纳 64K 点 + 帧头

struct rtsa_buffer_info {
    __u32 index;          // 缓冲槽索引 [0 .. RTSA_RING_BUFFER_COUNT-1]
    __u32 size;           // 实际有效载荷字节数
    __u64 sequence;       // 硬件/驱动帧计数
    __u64 timestamp_ns;   // 完成时间戳
    __u32 status;         // 0: OK, 1: Overflow/Error
};

#define RTSA_IOC_MAGIC       'R'
#define RTSA_IOC_START       _IO(RTSA_IOC_MAGIC, 1)                  // 启动 DMA 接收
#define RTSA_IOC_STOP        _IO(RTSA_IOC_MAGIC, 2)                  // 停止 DMA 接收
#define RTSA_IOC_DEQUEUE     _IOR(RTSA_IOC_MAGIC, 3, struct rtsa_buffer_info) // 取出已完成的缓冲
#define RTSA_IOC_QUEUE       _IOW(RTSA_IOC_MAGIC, 4, __u32)          // 归还缓冲回空闲队列

#endif
```

### 3. 内核驱动核心实现 (`rtsa_dma_driver.c`)

这是核心代码，包含环形缓冲管理、DMAEngine 调度、中断完成回调和用户态 mmap：

```c
#include <linux/module.h>
#include <linux/platform_device.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/dmaengine.h>
#include <linux/dma-mapping.h>
#include <linux/uaccess.h>
#include <linux/poll.h>
#include <linux/ktime.h>
#include "rtsa_dma_uapi.h"

#define DRIVER_NAME "rtsa_dma"

struct dma_slot {
    void *vaddr;             // CPU 虚拟地址
    dma_addr_t paddr;        // DMA 物理总线地址
    struct rtsa_buffer_info info;
};

struct rtsa_dma_dev {
    struct platform_device *pdev;
    struct cdev cdev;
    dev_t dev_node;
    struct class *class;
    struct device *device;

    struct dma_chan *rx_chan;
    struct dma_slot slots[RTSA_RING_BUFFER_COUNT];

    // 环形缓冲队列索引与同步
    wait_queue_head_t rx_wait;
    spinlock_t lock;
    __u32 completed_head;    // 完成队头
    __u32 completed_tail;    // 完成队尾
    __u32 completed_queue[RTSA_RING_BUFFER_COUNT];
    
    bool is_running;
    __u64 frame_seq;
};

// DMA 完成中断回调函数（运行在中断底半部/Tasklet 上下文）
static void rtsa_dma_rx_callback(void *param) {
    struct rtsa_dma_dev *rtsa = (struct rtsa_dma_dev *)param;
    unsigned long flags;
    __u32 slot_idx;

    spin_lock_irqsave(&rtsa->lock, flags);
    if (!rtsa->is_running) {
        spin_unlock_irqrestore(&rtsa->lock, flags);
        return;
    }

    slot_idx = rtsa->completed_queue[rtsa->completed_head];
    rtsa->slots[slot_idx].info.sequence = ++rtsa->frame_seq;
    rtsa->slots[slot_idx].info.timestamp_ns = ktime_get_ns();
    rtsa->slots[slot_idx].info.size = RTSA_BUFFER_SIZE; // 可由描述符取得或固定
    rtsa->slots[slot_idx].info.status = 0;

    // 推进完成指针并唤醒用户态 poll/select
    rtsa->completed_head = (rtsa->completed_head + 1) % RTSA_RING_BUFFER_COUNT;
    spin_unlock_irqrestore(&rtsa->lock, flags);

    wake_up_interruptible(&rtsa->rx_wait);
}

// 提交一个 DMA 接收描述符到 DMAEngine
static int rtsa_submit_rx_slot(struct rtsa_dma_dev *rtsa, __u32 slot_idx) {
    struct dma_async_tx_descriptor *desc;
    dma_cookie_t cookie;

    desc = dmaengine_prep_slave_single(
        rtsa->rx_chan,
        rtsa->slots[slot_idx].paddr,
        RTSA_BUFFER_SIZE,
        DMA_DEV_TO_MEM,
        DMA_PREP_INTERRUPT | DMA_CTRL_ACK
    );

    if (!desc) {
        dev_err(&rtsa->pdev->dev, "Failed to prepare DMA descriptor\n");
        return -ENOMEM;
    }

    desc->callback = rtsa_dma_rx_callback;
    desc->callback_param = rtsa;

    cookie = dmaengine_submit(desc);
    if (dma_submit_error(cookie)) {
        dev_err(&rtsa->pdev->dev, "DMA submit error\n");
        return -EIO;
    }

    dma_async_issue_pending(rtsa->rx_chan);
    return 0;
}

// mmap: 映射所有预分配的 DMA Coherent 物理连续缓冲到用户空间
static int rtsa_dma_mmap(struct file *filp, struct vm_area_struct *vma) {
    struct rtsa_dma_dev *rtsa = filp->private_data;
    size_t total_size = RTSA_RING_BUFFER_COUNT * RTSA_BUFFER_SIZE;

    if ((vma->vm_end - vma->vm_start) > total_size)
        return -EINVAL;

    // 将整个 Coherent 缓冲连续映射，设置非缓存或一致性属性
    return dma_mmap_coherent(&rtsa->pdev->dev, vma, rtsa->slots[0].vaddr,
                             rtsa->slots[0].paddr, vma->vm_end - vma->vm_start);
}

static __poll_t rtsa_dma_poll(struct file *filp, struct poll_table_struct *wait) {
    struct rtsa_dma_dev *rtsa = filp->private_data;
    __poll_t mask = 0;
    unsigned long flags;

    poll_wait(filp, &rtsa->rx_wait, wait);

    spin_lock_irqsave(&rtsa->lock, flags);
    if (rtsa->completed_head != rtsa->completed_tail) {
        mask |= EPOLLIN | EPOLLRDNORM; // 有数据可读
    }
    spin_unlock_irqrestore(&rtsa->lock, flags);

    return mask;
}

static long rtsa_dma_ioctl(struct file *filp, unsigned int cmd, unsigned long arg) {
    struct rtsa_dma_dev *rtsa = filp->private_data;
    unsigned long flags;
    int ret = 0;

    switch (cmd) {
    case RTSA_IOC_START:
        spin_lock_irqsave(&rtsa->lock, flags);
        if (!rtsa->is_running) {
            rtsa->is_running = true;
            rtsa->completed_head = 0;
            rtsa->completed_tail = 0;
            spin_unlock_irqrestore(&rtsa->lock, flags);

            // 预先向硬件下发初始的一批缓冲槽
            for (int i = 0; i < RTSA_RING_BUFFER_COUNT / 2; i++) {
                rtsa->completed_queue[i] = i;
                rtsa_submit_rx_slot(rtsa, i);
            }
        } else {
            spin_unlock_irqrestore(&rtsa->lock, flags);
        }
        break;

    case RTSA_IOC_STOP:
        spin_lock_irqsave(&rtsa->lock, flags);
        rtsa->is_running = false;
        spin_unlock_irqrestore(&rtsa->lock, flags);
        dmaengine_terminate_sync(rtsa->rx_chan); // 强行停止 DMA 传输
        wake_up_interruptible(&rtsa->rx_wait);
        break;

    case RTSA_IOC_DEQUEUE: {
        struct rtsa_buffer_info info;
        spin_lock_irqsave(&rtsa->lock, flags);
        if (rtsa->completed_head == rtsa->completed_tail) {
            spin_unlock_irqrestore(&rtsa->lock, flags);
            return -EAGAIN; // 无数据
        }
        __u32 slot = rtsa->completed_queue[rtsa->completed_tail];
        info = rtsa->slots[slot].info;
        info.index = slot;
        rtsa->completed_tail = (rtsa->completed_tail + 1) % RTSA_RING_BUFFER_COUNT;
        spin_unlock_irqrestore(&rtsa->lock, flags);

        if (copy_to_user((void __user *)arg, &info, sizeof(info)))
            return -EFAULT;
        break;
    }

    case RTSA_IOC_QUEUE: {
        __u32 slot_idx;
        if (copy_from_user(&slot_idx, (void __user *)arg, sizeof(slot_idx)))
            return -EFAULT;
        if (slot_idx >= RTSA_RING_BUFFER_COUNT)
            return -EINVAL;

        // 用户态处理完毕归还缓冲槽，重新挂入硬件 DMA
        ret = rtsa_submit_rx_slot(rtsa, slot_idx);
        break;
    }

    default:
        ret = -ENOTTY;
    }

    return ret;
}

static int rtsa_dma_open(struct inode *inode, struct file *filp) {
    struct rtsa_dma_dev *rtsa = container_of(inode->i_cdev, struct rtsa_dma_dev, cdev);
    filp->private_data = rtsa;
    return 0;
}

static const struct file_operations rtsa_dma_fops = {
    .owner          = THIS_MODULE,
    .open           = rtsa_dma_open,
    .mmap           = rtsa_dma_mmap,
    .poll           = rtsa_dma_poll,
    .unlocked_ioctl = rtsa_dma_ioctl,
};

static int rtsa_dma_probe(struct platform_device *pdev) {
    struct rtsa_dma_dev *rtsa;
    int ret, i;

    rtsa = devm_kzalloc(&pdev->dev, sizeof(*rtsa), GFP_KERNEL);
    if (!rtsa) return -ENOMEM;

    rtsa->pdev = pdev;
    spin_lock_init(&rtsa->lock);
    init_waitqueue_head(&rtsa->rx_wait);

    // 1. 获取 DMAEngine 绑定的 S2MM 通道
    rtsa->rx_chan = dma_request_chan(&pdev->dev, "rx_chan");
    if (IS_ERR(rtsa->rx_chan)) {
        dev_err(&pdev->dev, "Failed to request DMA channel rx_chan\n");
        return PTR_ERR(rtsa->rx_chan);
    }

    // 2. 申请 Coherent 连续物理缓冲
    for (i = 0; i < RTSA_RING_BUFFER_COUNT; i++) {
        rtsa->slots[i].vaddr = dma_alloc_coherent(
            &pdev->dev, RTSA_BUFFER_SIZE, &rtsa->slots[i].paddr, GFP_KERNEL
        );
        if (!rtsa->slots[i].vaddr) {
            dev_err(&pdev->dev, "DMA alloc buffer [%d] failed\n", i);
            return -ENOMEM;
        }
    }

    // 3. 注册字符设备 /dev/rtsa_dma
    alloc_chrdev_region(&rtsa->dev_node, 0, 1, DRIVER_NAME);
    cdev_init(&rtsa->cdev, &rtsa_dma_fops);
    cdev_add(&rtsa->cdev, rtsa->dev_node, 1);
    rtsa->class = class_create(THIS_MODULE, DRIVER_NAME);
    rtsa->device = device_create(rtsa->class, NULL, rtsa->dev_node, NULL, DRIVER_NAME);

    platform_set_drvdata(pdev, rtsa);
    dev_info(&pdev->dev, "RTSA Spectrum DMA driver probed successfully\n");
    return 0;
}

static int rtsa_dma_remove(struct platform_device *pdev) {
    struct rtsa_dma_dev *rtsa = platform_get_drvdata(pdev);

    device_destroy(rtsa->class, rtsa->dev_node);
    class_destroy(rtsa->class);
    cdev_del(&rtsa->cdev);
    unregister_chrdev_region(rtsa->dev_node, 1);

    for (int i = 0; i < RTSA_RING_BUFFER_COUNT; i++) {
        if (rtsa->slots[i].vaddr) {
            dma_free_coherent(&pdev->dev, RTSA_BUFFER_SIZE,
                              rtsa->slots[i].vaddr, rtsa->slots[i].paddr);
        }
    }
    dma_release_channel(rtsa->rx_chan);
    return 0;
}

static const struct of_device_id rtsa_dma_of_match[] = {
    { .compatible = "rtsa,spectrum-dma" },
    { /* sentinel */ }
};
MODULE_DEVICE_TABLE(of, rtsa_dma_of_match);

static struct platform_driver rtsa_dma_driver = {
    .probe  = rtsa_dma_probe,
    .remove = rtsa_dma_remove,
    .driver = {
        .name = DRIVER_NAME,
        .of_match_table = rtsa_dma_of_match,
    },
};
module_platform_driver(rtsa_dma_driver);

MODULE_AUTHOR("RTSA Team");
MODULE_DESCRIPTION("High-Performance Spectrum AXI DMA Driver");
MODULE_LICENSE("GPL");
```

### 4. 上位机用户态对接代码（C++ 封装，对接现有的 `IDmaDevice`）

上位机使用这个驱动时，核心读取循环极简且零拷贝：

```cpp
#include <fcntl.h>
#include <sys/mman.h>
#include <sys/ioctl.h>
#include <poll.h>
#include <unistd.h>
#include "rtsa_dma_uapi.h"

class LinuxDmaDevice {
public:
    bool openDevice() {
        fd_ = open("/dev/rtsa_dma", O_RDWR);
        if (fd_ < 0) return false;

        // mmap 整个环形缓冲区域
        size_t total_size = RTSA_RING_BUFFER_COUNT * RTSA_BUFFER_SIZE;
        base_mmap_ = (uint8_t*)mmap(nullptr, total_size, PROT_READ | PROT_WRITE, MAP_SHARED, fd_, 0);
        return base_mmap_ != MAP_FAILED;
    }

    void start() {
        ioctl(fd_, RTSA_IOC_START);
    }

    void stop() {
        ioctl(fd_, RTSA_IOC_STOP);
    }

    // 采集线程的工作循环
    bool waitForFrame(uint8_t*& out_buffer_ptr, uint32_t& out_slot_idx, int timeout_ms = 100) {
        struct pollfd pfd = { .fd = fd_, .events = POLLIN, .revents = 0 };
        int ret = poll(&pfd, 1, timeout_ms);
        if (ret <= 0) return false; // 超时或错误

        struct rtsa_buffer_info info;
        if (ioctl(fd_, RTSA_IOC_DEQUEUE, &info) < 0) return false;

        out_slot_idx = info.index;
        out_buffer_ptr = base_mmap_ + (info.index * RTSA_BUFFER_SIZE);
        return true;
    }

    void releaseFrame(uint32_t slot_idx) {
        ioctl(fd_, RTSA_IOC_QUEUE, &slot_idx);
    }

    ~LinuxDmaDevice() {
        stop();
        if (base_mmap_) munmap(base_mmap_, RTSA_RING_BUFFER_COUNT * RTSA_BUFFER_SIZE);
        if (fd_ >= 0) close(fd_);
    }

private:
    int fd_ = -1;
    uint8_t* base_mmap_ = nullptr;
};
```

### 5. 必须警惕的 3 个关键坑

1. **总线地址位宽（32位 vs 64位）**：
   - ZU47DR 是 64 位 AArch64 系统。在 Vivado 中配置 AXI DMA IP 时，若勾选了 **`Enable 64-bit Address`**，内核 DMA 必须支持 64 位寻址。在 `probe` 函数开头必须加上：
     ```c
     dma_set_mask_and_coherent(&pdev->dev, DMA_BIT_MASK(64));
     ```
     否则当内存分配在高地址（高于 4GB）时，DMA 会向错误物理地址写数据，导致硬件总线崩溃。
2. **Scatter-Gather (SG) 模式必须在 Vivado 中开启**：
   - 连续流式接收（如 1000 FPS）严禁使用 Simple DMA 模式（Simple 模式每次传输完必须由 CPU 重新配置寄存器，极易引起丢帧）；必须开启 Scatter-Gather 模式，由底层 `xilinx_dma.c` 自动加载描述符链表。
3. **关闭非必要内核日志**：
   - 每秒传输上千帧时，中断处理函数及 `callback` 内**严禁用 `printk`/`dev_info` 打印日志**，一条串口日志的耗时（几毫秒）就会让 DMA 环形缓冲瞬间被后续数据打满溢出。

### 二、从 `pl.dtsi` 提取的 4 个致命硬件参数（必须防坑）

#### 1. 物理地址位宽是 32 位（`xlnx,addrwidth = <0x20>`）
* **硬件现状**：你的 AXI DMA IP 被配置为了 **32 位寻址**，而不是 64 位。
* **致命风险**：ZU47DR 是 64 位 ARM（AArch64），板载 DDR 物理地址往往映射在 `0x0000_0000` 到更高空间（甚至超过 4GB）。如果 DMA 只有 32 位地址总线，一旦内存分配到了 4GB 以上的高地址，DMA 写入会截断高 32 位，**引发总线崩溃（Kernel Panic / SError）**。
* **驱动必须增加的代码**：在 `rtsa_dma_driver.c` 的 `rtsa_dma_probe()` 开头，**必须显式限制 32 位 DMA 掩码**：
  ```c
  // 必须加在 rtsa_dma_probe 开头，强制内核只在低 4GB 内存中分配物理缓冲
  ret = dma_set_mask_and_coherent(&pdev->dev, DMA_BIT_MASK(32));
  if (ret) {
      dev_err(&pdev->dev, "No suitable DMA available\n");
      return ret;
  }
  ```

#### 2. 通道类型：只有单向 S2MM 接收通道
* `dma-channel@a0080030` 的 `compatible = "xlnx,axi-dma-s2mm-channel"`。
* 没有配置 MM2S（发送）通道，设备只有 1 个通道。所以设备树里引用的通道号只能是 `0`（即 `<&axi_dma_0 0>`）。

#### 3. AXI4-Stream 数据总线宽度是 64 bit（`xlnx,datawidth = <0x40>`）
* **数据对齐**：总线每个 beat 传输 64 位（8 字节）。
* 你的频谱帧（64 字节帧头 + N 个频点数据）**总字节数必须是 8 字节的整数倍**。
* 例如：64 字节头 + 16,384 点 × 4 字节/点 = 65,600 字节（能被 8 整除），满足总线节拍要求。

#### 4. 单次最大包长限制为 8 MB（`xlnx,sg-length-width = <0x17>`）
* SG 缓冲区长度位宽是 23 位（$2^{23} - 1 = 8\text{ MB}$）。
* 我们的频谱单帧最大（65,536 点 × 4 字节 ≈ 256 KB）远小于 8 MB，**1 帧对应 1 个 DMA 描述符即可满速流式传输**，无需做繁复的分包重组。
