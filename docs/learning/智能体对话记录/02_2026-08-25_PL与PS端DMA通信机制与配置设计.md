### 🤖 智能体回复

打通 PL（ZU47DR / Zynq）与 PS 之间的 AXI DMA，核心是将 **PL 侧的 AXI4-Stream 数据流（含帧头和 TLAST）**，通过 **AXI DMA IP** 搬移到 **PS DDR 环形缓冲区**，并在 **PS 端（Linux/驱动/C++）** 完成解析并注入现有的 `SpectrumPipeline`。

以下是 PL 和 PS 两端从硬件到软件的完整具体配置与代码实现。

---

### 1. 全局数据流与接口协议（打通基准）

```text
[PL 数据面]
FFT 结果 (频点功率) ──> [Frame Packer (插入64B帧头 + 生成TLAST)] 
                   ──> [AXI-Stream FIFO] 
                   ──> [AXI DMA (S2MM)] 
                   ──> [PS AXI_HP/HPC] ──> [PS DDR 环形缓冲]

[PS 软件面]
[PS DDR] ──> [Linux DMA 驱动 / DMA Proxy] 
         ──> [DmaSpectrumSource (用户态Worker线程)]
         ──> [SpectrumFrameParser & RawSpectrumConverter (定点->float)]
         ──> [SpectrumPipeline -> LatestFrameStore -> Qt界面]

[控制面]
Qt 参数调整 ──> [AXI-Lite 寄存器 (中心频率/Span/FFT点数/Epoch)] ──> [PL 控制逻辑]
```

### 2. PL 端配置与实现 (Vivado & RTL)

#### (1) Vivado Block Design (BD) IP 配置
1. **AXI Direct Memory Access (AXI DMA) IP**:
   - **Mode**: 仅勾选 `Enable Read Channel (S2MM)`（PL 到 PS 单向接收，关闭 MM2S 节省资源）。
   - **Scatter Gather Engine**: 勾选 `Enable Scatter Gather`（**极力推荐**，1000 FPS 下 Direct Register 模式每帧都要 CPU 介入写寄存器，会导致中断开销和 Backpressure 溢出）。
   - **Width of Buffer Length Register**: 设为 `23` 或 `26`。
   - **Stream Data Width**: 设为 `32` 或 `64`（根据吞吐率决定；16384 点 @ 1000 FPS 约需 65.5 MB/s，32-bit @ 100MHz 理论上限 400 MB/s 足够）。
   - **Memory Map Data Width**: 设为 `64` 或 `128`。
   - **Max Burst Size**: 设为 `128` 或 `256`。
2. **总线互联与端口映射**:
   - `M_AXI_S2MM` 和 `M_AXI_SG` $\rightarrow$ 连接到 Zynq MPSoC 的 `S_AXI_HP0_FPD`（或 `S_AXI_HPC0_FPD`）。
   - `S_AXI_LITE` $\rightarrow$ 连接到 PS 的 `M_AXI_HPM0_FPD`（通过 AXI Interconnect 寻址）。
   - **中断**: `s2mm_introut` $\rightarrow$ 连入 PS 的 `pl_ps_irq0[0]`。
3. **AXI4-Stream Data FIFO**:
   - 插入在 FFT 打包逻辑与 AXI DMA `S_AXIS_S2MM` 之间，深度建议 $\ge 4096$ 深度（BRAM/URAM），吸收 DDR 访问抖动。

#### (2) PL 侧核心 RTL：帧头打包与 TLAST 发生器 (`axis_frame_packer.v`)
AXI DMA S2MM **严格依赖 `TLAST` 判定一帧传输完成**。必须在 FFT 频点流前插入 64 字节帧头，并在最后一个频点拉高 `TLAST`。

```verilog
module axis_frame_packer #(
    parameter HEADER_WORDS = 16,     // 64 Bytes (16 x 32-bit words)
    parameter MAGIC_NUM    = 32'h52545341 // "RTSA"
)(
    input  wire        clk,
    input  wire        rst_n,
    
    // 来自控制面的动态参数
    input  wire [31:0] cfg_bin_count,
    input  wire [63:0] cfg_center_freq_hz,
    input  wire [63:0] cfg_span_hz,
    input  wire [31:0] cfg_epoch,
    
    // 来自 FFT 模块的原始 AXI-Stream (假设 32-bit Q8 定点功率)
    input  wire [31:0] s_axis_fft_tdata,
    input  wire        s_axis_fft_tvalid,
    output wire        s_axis_fft_tready,
    input  wire        s_axis_fft_tlast, // FFT 自带的一帧结束
    
    // 输出给 AXI DMA 的完整 AXI-Stream
    output reg  [31:0] m_axis_dma_tdata,
    output reg         m_axis_dma_tvalid,
    input  wire        m_axis_dma_tready,
    output reg  [3:0]  m_axis_dma_tkeep,
    output reg         m_axis_dma_tlast
);

    localparam ST_IDLE       = 2'd0;
    localparam ST_HEADER     = 2'd1;
    localparam ST_PAYLOAD    = 2'd2;
    
    reg [1:0]  state;
    reg [3:0]  hdr_idx;
    reg [63:0] frame_seq;
    reg [31:0] bin_counter;

    // 64 字节 Header 静态/动态字段生成
    reg [31:0] header_rom [0:15];
    always @(*) begin
        header_rom[0]  = MAGIC_NUM;                          // magic (0x52545341)
        header_rom[1]  = {16'd64, 16'd1};                    // headerBytes(64) | version(1)
        header_rom[2]  = 32'd64 + (cfg_bin_count << 2);      // totalBytes
        header_rom[3]  = 32'h00000001;                       // flags (e.g. FFT_SHIFTED)
        header_rom[4]  = frame_seq[31:0];                    // sequence low
        header_rom[5]  = frame_seq[63:32];                   // sequence high
        header_rom[6]  = 32'd0;                              // timestamp low (由PL计时器提供)
        header_rom[7]  = 32'd0;                              // timestamp high
        header_rom[8]  = cfg_center_freq_hz[31:0];          // centerFreq low
        header_rom[9]  = cfg_center_freq_hz[63:32];         // centerFreq high
        header_rom[10] = cfg_span_hz[31:0];                 // span low
        header_rom[11] = cfg_span_hz[63:32];                // span high
        header_rom[12] = cfg_bin_count;                     // binCount
        header_rom[13] = (cfg_bin_count << 2);              // payloadBytes
        header_rom[14] = {16'd1, 16'd2};                    // amplitudeUnit(dBFS) | sampleFormat(S32_DB_Q8)
        header_rom[15] = cfg_epoch;                         // configurationEpoch
    end

    assign s_axis_fft_tready = (state == ST_PAYLOAD) && m_axis_dma_tready;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            state             <= ST_IDLE;
            hdr_idx           <= 4'd0;
            frame_seq         <= 64'd0;
            bin_counter       <= 32'd0;
            m_axis_dma_tvalid <= 1'b0;
            m_axis_dma_tlast  <= 1'b0;
            m_axis_dma_tkeep  <= 4'b1111;
        end else begin
            case (state)
                ST_IDLE: begin
                    m_axis_dma_tlast <= 1'b0;
                    if (s_axis_fft_tvalid) begin
                        state             <= ST_HEADER;
                        hdr_idx           <= 4'd0;
                        m_axis_dma_tdata  <= header_rom[0];
                        m_axis_dma_tvalid <= 1'b1;
                    end
                end

                ST_HEADER: begin
                    if (m_axis_dma_tready) begin
                        if (hdr_idx == HEADER_WORDS - 1) begin
                            state             <= ST_PAYLOAD;
                            bin_counter       <= 32'd0;
                            m_axis_dma_tdata  <= s_axis_fft_tdata;
                            m_axis_dma_tvalid <= s_axis_fft_tvalid;
                        end else begin
                            hdr_idx           <= hdr_idx + 1'b1;
                            m_axis_dma_tdata  <= header_rom[hdr_idx + 1'b1];
                            m_axis_dma_tvalid <= 1'b1;
                        end
                    end
                end

                ST_PAYLOAD: begin
                    if (m_axis_dma_tready && s_axis_fft_tvalid) begin
                        bin_counter <= bin_counter + 1'b1;
                        m_axis_dma_tdata  <= s_axis_fft_tdata;
                        m_axis_dma_tvalid <= 1'b1;

                        // 最后一个频点：强制产生 TLAST
                        if (bin_counter == cfg_bin_count - 1 || s_axis_fft_tlast) begin
                            m_axis_dma_tlast  <= 1'b1;
                            frame_seq         <= frame_seq + 1'b1;
                            state             <= ST_IDLE;
                        end
                    end else if (m_axis_dma_tready && !s_axis_fft_tvalid) begin
                        m_axis_dma_tvalid <= 1'b0;
                    end
                end
            endcase
        end
    end
endmodule
```

#### (2) 协议校验与定点转换器 [`SpectrumFrameParser.h`](file:///d:/Study/codex/RTSA/src/protocol/SpectrumFrameParser.h)
严格防守式校验，防止乱码或半包导致崩盘。

```cpp
#pragma once
#include "core/SpectrumFrame.h"
#include <cstdint>
#include <cstring>

#pragma pack(push, 1)
struct SpectrumWireHeader {
    uint32_t magic;               // 0x52545341 ("RTSA")
    uint16_t protocolVersion;     // 1
    uint16_t headerBytes;         // 64
    uint32_t totalBytes;
    uint32_t flags;
    uint64_t sequence;
    uint64_t timestampNs;
    uint64_t centerFreqHz;
    uint64_t spanHz;
    uint32_t binCount;
    uint32_t payloadBytes;
    uint16_t sampleFormat;        // 2 = S32_DB_Q8
    uint16_t amplitudeUnit;
    uint32_t epoch;
};
#pragma pack(pop)

class SpectrumFrameParser {
public:
    static bool parseAndConvert(const uint8_t* rawData, size_t validBytes, SpectrumFrame& outFrame) {
        if (validBytes < sizeof(SpectrumWireHeader)) return false;

        const auto* hdr = reinterpret_cast<const SpectrumWireHeader*>(rawData);
        if (hdr->magic != 0x52545341 || hdr->headerBytes != 64) return false;
        if (validBytes < hdr->totalBytes || hdr->payloadBytes != (hdr->binCount * sizeof(int32_t))) return false;

        // 填充元数据
        outFrame.metadata.centerFrequencyHz = static_cast<double>(hdr->centerFreqHz);
        outFrame.metadata.spanHz = static_cast<double>(hdr->spanHz);
        outFrame.metadata.binCount = hdr->binCount;
        outFrame.metadata.sequence = hdr->sequence;

        // 定点转换：S32_DB_Q8 (1 LSB = 1/256 dBFS) -> float
        outFrame.bins.resize(hdr->binCount);
        const int32_t* payload = reinterpret_cast<const int32_t*>(rawData + hdr->headerBytes);
        constexpr float scale = 1.0f / 256.0f;

        for (uint32_t i = 0; i < hdr->binCount; ++i) {
            outFrame.bins[i] = static_cast<float>(payload[i]) * scale;
        }

        return true;
    }
};
```

#### (3) 数据源实现 [`DmaSpectrumSource.cpp`](file:///d:/Study/codex/RTSA/src/sources/DmaSpectrumSource.cpp)
接入现有系统的 `ISpectrumSource`，在独立工作线程中泵送数据。

```cpp
#include "DmaSpectrumSource.h"
#include "protocol/SpectrumFrameParser.h"
#include <thread>
#include <atomic>

void DmaSpectrumSource::workerThread() {
    DmaBufferSlot slot;
    auto frame = std::make_shared<SpectrumFrame>();

    while (m_running.load(std::memory_order_relaxed)) {
        // 1. 等待 DMA 完成帧
        if (!m_dmaDevice.dequeueCompleted(slot, 100)) {
            m_stats.timeoutCount++;
            continue;
        }

        // 2. 解析与定点转 float
        if (SpectrumFrameParser::parseAndConvert(slot.virtAddr, slot.length, *frame)) {
            m_stats.framesReceived++;
            // 3. 发布给 SpectrumPipeline
            if (m_frameSink) {
                m_frameSink(frame);
            }
            // 准备下一帧独立 buffer
            frame = std::make_shared<SpectrumFrame>();
        } else {
            m_stats.protocolErrors++;
        }

        // 4. 立即释放并归还 DMA 环形缓冲
        m_dmaDevice.returnBuffer(slot.index);
    }
}
```

### 5. 联调排错与关键检查清单

1. **PL 侧 ILA 抓信号（务必先于 PS 联调）**：
   - 抓取 AXI DMA 的 `S_AXIS_S2MM` 接口：
     - 检查 `TLAST` 是否**恰好**在第 $16 + N$ 个 word 拉高且仅维持 1 拍。
     - 检查在 `TREADY` 为低时，`TVALID` 与 `TDATA` 是否保持稳定。
2. **DMA 挂死（Halt / Error）排查**：
   - 如果 DMA 启动后接收 1 帧就停止，99% 是 **`TLAST` 丢失** 或 **传输长度不匹配**。
   - 读取 DMA 状态寄存器 `S2MM_DMASR` (偏移 `0x34`)：
     - Bit 0: `Halted` (是否停止)
     - Bit 1: `Idle` (是否空闲)
     - Bit 4: `DMAIntErr` (内部错误，通常是地址对齐或突发越界)
     - Bit 5: `DMASlvErr` (从机响应错误，AXI HP 互联配置错误)
     - Bit 6: `DMADecErr` (解码错误)
3. **Cache 一致性避坑**：
   - 如果上位机读出的帧头 `magic` 一直是全 0 或旧数据，说明 CPU 读取的是脏 Cache。
   - 驱动在把 Buffer 交付用户态前，必须执行 `dma_sync_single_for_cpu` 或分配内存时标记 `dma_alloc_coherent`。
