### 修改说明

#### 1. 采集控制按钮精简合并
- 右上角仅保留两个并排按钮：`[开始 / 停止]` 和 `[单次]`。
- **开始/停止按钮状态自适应**：
  - 停止/暂停状态下显示绿色 `▶ 开始 / 连续`，单次按钮可用；
  - 运行中自动切换为红色 `■ 停止`，单次按钮禁用。

#### 2. 暂停/停止状态下波形实时响应参数修改
- 修改了 [`SimulatedSpectrumSource::configure`](file:///d:/Study/codex/RTSA/src/sources/SimulatedSpectrumSource.cpp)：在暂停/停止状态下修改中心频率、频宽（Span）、起始/终止频率、噪声底或单音时，会即时生成静态预览帧并触发 0 延时重绘。
- 支持在暂停状态下直接通过滚轮缩放、鼠标左键拖拽平移中心频率或微调 SpinBox，波形即时动态移动。

#### 3. 常用频宽一键快捷按钮
- 在【数据源与频率】面板的“频宽（Span）”输入框下方新增了常用频宽快捷按钮网格：
  `[10M]` `[20M]` `[50M]` `[100M]` `[200M]` `[500M]` `[1.0G]` `[全频宽]`
- 点击对应按钮直接一键设为目标频宽并刷新波形。

#### 4. 一键 AUTO 自动寻峰与设置（类似示波器 AUTO 键）
- **功能区分**：
  - **自动幅度刻度 (`Ctrl+R`)**：只针对当前已显示波形自适应 Y 轴上下限（参考电平与底电平）；
  - **⚡ 一键自动设置 (`F5` / AUTO)**：
    1. 即使当前画面全是噪声（信号偏离当前视图），自动全频段搜索最高主信号；
    2. 自动把**中心频率**对齐到该信号峰值；
    3. 自动设置**最佳频宽（Span）**（自适应设为 50M ~ 100M 令信号居中清晰）；
    4. 自动优化**幅度刻度**（留出 10 dB Headroom 顶格余量）；
    5. 自动激活并标定 **Marker 1** 到信号峰值频率上。
- **入口**：幅度面板新增醒目的青色 `⚡ 一键自动设置 (AUTO / F5)` 按钮、菜单栏【显示】->【一键自动设置】及全局快捷键 `F5`。

### 错位根因与解释

你在全屏后看到的现象是：**上半部分（全屏后新来的帧）横跨全屏，下半部分（全屏前的历史数据）被压缩在左半边，右下角留有一大块黑斑断层**。

**代码根本原因**在 [`WaterfallPlotWidget::resizeImageBuffer`](file:///d:/Study/codex/RTSA/src/plot/WaterfallPlotWidget.cpp#L106)：
```cpp
// 旧代码
const int copyCols = std::min(bufferWidth_, newWidth);
std::memcpy(dstScan, srcScan, static_cast<std::size_t>(copyCols));
```
- 进入全屏时，瀑布图像素宽度从窗口宽度（如 852 px）瞬间扩大为全屏宽度（如 1772 px）；
- 原代码仅使用 `std::memcpy` 拷贝了旧行的前 852 字节，剩余的 (1772 - 852 = 920) 字节全部留白为 0（显示为**右下角的黑色空白方块**）；
- 并且旧数据中原本对应全频段的频点未做横向重采样拉伸，全被挤在左侧前 852 列（**下半部分信号被压缩到左边**）；
- 当全屏后新帧以 1772 满宽写入后，新旧两段就在切换时刻发生了明显的错位与截断。

### 修复方案与实际代码

重构了 [`WaterfallPlotWidget::resizeImageBuffer`](file:///d:/Study/codex/RTSA/src/plot/WaterfallPlotWidget.cpp#L106)，在宽度变化时对历史行进行**横向重采样**：
1. **放大拉伸（如进入全屏 `newWidth > bufferWidth_`）**：
   使用双线性插值（Bilinear Interpolation）把历史行平滑扩展至 `newWidth`，信号条纹在全屏前后频率位置 1:1 连续无缝拼接，消除右侧黑斑；
2. **缩小（如退出全屏 `newWidth < bufferWidth_`）**：
   使用峰值保持（Peak-Hold）重采样，保证窗口缩小时单音或窄带信号依然清晰可见，不被抽样丢失。

#### 根因排查

1. **构建强制 0 横向位移的专用视口**：重写 `scrollContentsBy(int dx, int dy)`，将横向滚动脉冲直接抹平为 0：
   ```cpp
   class NoHorizontalScrollArea final : public QScrollArea {
   public:
       explicit NoHorizontalScrollArea(QWidget* parent = nullptr) : QScrollArea(parent) {
           setWidgetResizable(true);
           setFrameShape(QFrame::NoFrame);
           setHorizontalScrollBarPolicy(Qt::ScrollBarAlwaysOff);
           horizontalScrollBar()->setEnabled(false);
       }
   protected:
       void scrollContentsBy(int /*dx*/, int dy) override {
           QScrollArea::scrollContentsBy(0, dy); // 永远禁止横向滚动
       }
   };
   ```
