审查报告中的问题已全部核实并确认存在。目前已完成全面的代码优化与系统性修复，具体改动如下：

### 1. 关键问题修复与优化

1. **并发与数据竞争消除 (P0-01, P0-03, P1-11, P2-06)**
   - **`MarkerEngine` 隔离**：由 T2 线程独占，UI 不再持有引擎可变引用。UI 操作通过 [`DataProcessor`](file:///d:/Projects/RTSA/src/core/DataProcessor.h) 的命令队列（`MarkerCommand`）顺序入队，T2 处理后随 [`ProcessedFrame`](file:///d:/Projects/RTSA/src/core/ProcessedFrame.h) 发送不可变的 `MarkerSnapshot` 快照供 [`SpectrumPlot`](file:///d:/Projects/RTSA/src/ui/SpectrumPlot.cpp) 和 [`MarkerCard`](file:///d:/Projects/RTSA/src/ui/panels/MarkerCard.cpp) 渲染。
   - **`MockDmaManager` 加锁快照**：添加 `std::mutex m_configMutex`，在 `generateFrame()` 启动时加锁拷贝配置快照（Center, Span, NoiseFloor, Signals），彻底消除跨线程参数撕裂与 vector 遍历崩溃隐患。
   - **统计量原子化**：`processedFrameCount()` 与 `droppedFrameCount()` 改为 `std::atomic<uint64_t>`，去除静态局部工作缓冲。

2. **三缓冲防丢失唤醒 (P0-04)**
   - 重构 [`TripleBuffer`](file:///d:/Projects/RTSA/src/hal/TripleBuffer.h)：将 pending 索引与 `HAS_NEW_DATA` 标志合并为单个原子变量 `m_pendingState`，生产者用 atomic exchange，消费者用 CAS 消费，杜绝独立布尔标志被覆盖导致的丢唤醒问题。

3. **参数校验与起止频率联动防重入 (P1-02, P1-03, P3-03, P3-08)**
   - **组合边界校验**：[`ParamTransaction::validate()`](file:///d:/Projects/RTSA/src/core/ParamTransaction.cpp) 增加 `std::isfinite` 及 `Center ± Span/2` 物理边界校验（`10 MHz ~ 6.0 GHz`）；`rollback()` 真正恢复 pending 参数为已提交快照。
   - **起止频率单信号**：[`BottomParamBar`](file:///d:/Projects/RTSA/src/ui/panels/BottomParamBar.cpp) 增加 `freqRangeChanged(center, span)` 组合信号，彻底解决分步发信号导致旧 Span 覆盖新值的问题。

4. **数据契约与瀑布图锯齿修复 (P1-08, P1-09)**
   - **MinMax 契约**：[`TraceDecimator::decimateMinMax`](file:///d:/Projects/RTSA/src/core/TraceDecimator.cpp) 无论输入点数多少均统一按列输出 min/max 对。
   - **瀑布图等距采样**：新增 `decimateEqualInterval` 输出 `waterfalldBm`，消除瀑布图相邻像素交替采 min/max 引起的横向锯齿纹理。

5. **峰值居中与丢帧统计 (P1-01, P1-10)**
   - **峰值居中闭环**：峰值居中由 T2 搜峰完成后发出 `peakToCenterCalculated(peakFreqHz)` 信号，UI 线程接收后同步应用新中心频率。
   - **首段丢帧捕获**：引入 `m_hasLastFrame` 标志，修复 `frameId` 从 0 开始时首段跳帧漏统计的问题。

6. **UI 缓存重算与导出毫秒时间戳 (P2-01, P2-10, P2-11)**
   - 缓存最新一帧，在窗口 resize 或调整刻度时即使处于停止状态也能立即重新映射坐标。
   - 截图与 CSV 导出文件名加入毫秒时间戳 `yyyyMMdd_hhmmss_zzz`，防止同秒重复覆盖，并使用同一拍捕获快照。

7. **日志与状态机 (P3-01, P3-02, P3-04, P3-05)**
   - 修复 [`FsmController`](file:///d:/Projects/RTSA/src/core/FsmController.cpp) 状态日志打印重复问题；[`Logger`](file:///d:/Projects/RTSA/src/common/Logger.cpp) 的级别改为 `std::atomic<LogLevel>`；[`CMakeLists.txt`](file:///d:/Projects/RTSA/CMakeLists.txt) 版本统一为 `2.1.0` 且优化仅对 Release 生效。
