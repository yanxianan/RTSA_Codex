### 二、如何回退（常见场景与命令）

#### 1. 丢弃当前未提交的本地临时修改
放弃工作区的所有未暂存修改（如 IDE 生成的配置文件）：
```bash
# 放弃所有工作区修改
git restore .

# 清理未跟踪的新增文件/目录
git clean -fd
```

#### 2. 安全回退某一次提交（推荐，保留历史记录）
生成一个内容相反的新提交来抵消目标 commit，适合已推送到远程的提交：
```bash
# 撤销最近一次提交的内容
git revert HEAD

# 撤销指定的某次 commit（例如 e158cd0）
git revert e158cd0
```

#### 3. 强制回退到历史版本（丢弃后续提交）
如果要彻底回退到某个版本：
```bash
# 1. 回退到指定 commit，保留工作区代码（代码变成未提交状态）
git reset --soft <commit_id>

# 2. 彻底抹除该 commit 之后的所有修改（危险，工作区改动全清空）
git reset --hard <commit_id>
# 例如回退到 e6f95d0：
git reset --hard e6f95d0

# 如果已经 push 到远程，需要强制推送覆盖（团队协作慎用）：
git push origin main --force
```

#### 4. 仅查看/测试历史版本（不影响当前分支）
从历史某个 commit 检出一个新分支去排查：
```bash
git checkout -b test-old-version <commit_id>
```

#### 5. 仅回退指定单个文件
只把某个文件还原到某个历史版本或最近提交：
```bash
# 还原到最新 commit 的状态
git restore <file_path>

# 还原到指定历史 commit 的状态
git checkout <commit_id> -- <file_path>
```
